# Mandatum — new visual direction

Status: two distinct local prototypes for user review; V3 overall style rejected. No publication approved.
Reference: https://masterborn.ai/ — inspected visually November 13, 2026. User attributed the admired work to Damian Fejdasz; authorship was not independently verified.

## Visual contract
One dominant animated career story, quiet supporting layout. Deep navy canvas, off-white text, muted steel blue light. Modern sans-serif display typography, deliberate large scale and negative space. Fine flowing lines may support the focal point but no camo, charts, painterly scenes or competing decorative systems. Keep Mandatum branding, truthful copy and original logo. Retain square arrow-free primary/secondary controls. This is an interpretation of composition and restraint, not a copy of MasterBorn branding, source or assets.

## Preserve from previous work
- Animated Mandatum logo.
- Hero interactions and LinkedIn-style career transition; explicitly illustrative profiles remain labeled as examples.
- Film and its readable caption.
- Audience-label decipher, e.g. For future Fellows.
- The experience is already there and the exact Foundation introduction.
- Partner logos alongside explanatory text.
- Complete authentic testimonials. New requirement: scroll advances cards and reveals more text, with full-content keyboard/touch/reduced-motion fallback.

## Prototype scope
`/review/direction/index.html` is a representative landing, separate from V1/V2/V3. Evaluate hero, intro, film, testimonials and partner arrangement together before broad rollout. Do not claim the old styleguide is accepted or convert all pages before seeing whether this direction works.

## Working method for agents
Reference → explicit visual rules → one coherent rendered prototype → inspect desktop/mobile and motion states → user reaction → propagate. Review against composition, type hierarchy, density, palette and focal hierarchy, not a count of requested effects. Avoid adding new visual devices to solve a mismatch. Functional tests cannot establish design quality.

## Two variants — explicit user request
User supplied the frontend-design skill text and explicitly requested a second agent and a genuinely different variant. Apply plan → brief check → build → visual critique. User instructions win over skill defaults (keep requested label cipher and square controls).

A (`/review/direction/index.html`): dark navy, spatial centered career profile, large restrained sans heading, quiet technical depth.
B (`/review/direction-b/index.html`): crisp light/mineral, asymmetric human/film-first composition, different hierarchy and image-to-type ratio, supporting career profile. No cream/serif reset or palette-only reskin of A.

These are new direction A/B, not replacements for original V1/V2/V3. Compare composition, dominant element, typography, media treatment and scroll narrative. Both keep factual content and accepted mechanisms.
